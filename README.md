# 🛒 Amazon Homepage Clone

A pixel-accurate recreation of the Amazon homepage built with pure HTML and CSS — no JavaScript frameworks, no templates.

## ✨ Features

- Full navbar with logo, location, search bar, sign-in, and cart sections
- Secondary navigation panel with department links
- Product category grid using CSS Flexbox and Grid
- Custom search bar with dropdown department selector
- Font Awesome icons for UI elements
- Fully responsive layout structure

## 🛠️ Tech Stack

`HTML5` `CSS3` `Flexbox` `CSS Grid` `Font Awesome`

## 🚀 How to Run

```bash
git clone https://github.com/charat-toomer/amazon-homepage-clone.git
cd amazon-homepage-clone
open index.html
```
